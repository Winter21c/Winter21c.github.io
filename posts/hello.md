## 欢迎来到「不完美笔记」

这是站点自带的一篇**模板文章**。它的作用是：

1. 告诉你文章文件长什么样；
2. 顺便让「归档」页面有内容可渲染。

> ⚠️ 一个技术限制：本站是静态导出到 GitHub Pages 的，
> `posts/` 目录**至少要保留一篇文章**，否则构建会失败。
> 所以请直接**改写这篇**，而不是把它删空。

---

## 怎么写新文章

在项目根目录的 `posts/` 文件夹里新建一个 `.md` 文件，
**文件名就是网址**：

```
posts/我的第一篇笔记.md
   ↓
https://winter21c.github.io/posts/我的第一篇笔记/
```

文件最上方用 `---` 包起来的那一段叫 front-matter，用来描述这篇文章：

```markdown
---
title: "文章标题"
date: "2026-09-26 10:00:00"
description: "一句话摘要，会显示在列表里"
cover: "封面图链接，留空则用默认封面"
tags: ["标签一", "标签二"]
---
```

下面就可以正常写 Markdown 正文了，支持：

- **加粗**、*斜体*、`行内代码`
- 列表、引用、表格
- 代码高亮
- 数学公式（KaTeX）：行内 $E = mc^2$，块级 $$ \int_0^1 x^2 dx $$

---

## 写完怎么发布

```bash
git add .
git commit -m "新文章"
git push
```

推送后 GitHub Actions 会自动构建并发布，大约 1~2 分钟生效。

进度可以在仓库的 **Actions** 标签页查看。

## 还有两个板块

- **杂谈**（`chatters/` 目录）：偏随笔、碎碎念
- **说说**（`moments/` 目录）：像朋友圈一样的短内容

它们的写法和文章一样，都是 Markdown + front-matter。
